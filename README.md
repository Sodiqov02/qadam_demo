# Qadam Static Demo

Pure static GitHub Pages demo for the Qadam storefront.

## Structure

- `index.html` - demo page
- `static/` - CSS and JavaScript
- `data/menu.json` - local demo menu data
- `assets/menu/` - local menu images

## GitHub Pages

Serve the repository root. The page loads local assets with relative paths:

- `./static/style.css`
- `./static/script.js`
- `./data/menu.json`
- `./assets/menu/...`
